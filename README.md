# macOS-Big-Sur-Installation-Lab
Step-by-step macOS Big Sur disk formatting and installation documentation with screenshots

**Project Overview
**
This project documents the installation workflow of macOS Big Sur through practical screenshots and step-by-step technical documentation.

The objective is to demonstrate familiarity with macOS installation procedures, software license agreements, installation preparation, and initial system configuration.

Technologies & Tools

macOS Big Sur

macOS Installer / ISO file

Apple ID sign in and setup cloud sync.

**Installation Documentation
**
Step 1: macOS Big Sur License Agreement

The installer displays the Apple Software License Agreement, which must be reviewed and accepted before continuing.


Step 2: Installation Preparation

Document the installation destination and preparation steps with screenshots.

Step 3: Installation Process

Document the installation progress and relevant installation stages.

Step 4: Initial Configuration

If installation is completed, document the initial macOS setup and desktop environment.
